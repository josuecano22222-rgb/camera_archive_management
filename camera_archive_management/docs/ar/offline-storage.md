# تخزين الخرائط ومجموعات البيانات دون اتصال

يتضمن التطبيق Leaflet 1.9.4 وملف حدود عالمي عام من Natural Earth بمقياس 1:110m. ولا يتضمن بلاطات نقطية أو بيانات اعتماد مزود أو مجموعات بيانات إدارية بمقياس وطني. راجع إشعارات ترخيص المكونات والإسناد المجاورة قبل إعادة توزيع الأصول.

## حفظ خريطة المتصفح

توفر خريطة أرشيف الكاميرات خياراً صريحاً **Save map snapshot, details and images offline** (حفظ لقطة الخريطة والتفاصيل والصور دون اتصال). وهو معطل افتراضياً. عند تفعيله، تحفظ حمولة الخريطة الحالية بعد تطبيق عوامل التصفية، وسجلات النوافذ المنبثقة للكاميرات/الأحداث التي فتحها المشغل، والصور التي عُرضت، في IndexedDB بالمتصفح، ضمن مساحة أسماء مقيدة بمصدر الموقع ومستخدم Frappe. تستخدم تنزيلات الصور طلبات مصادقاً عليها من المصدر نفسه، ولا تخزن إلا استجابات الصور. تحد حدود التخزين لكل لقطة وصورة وعدد الإدخالات والإجمالي من استخدام المتصفح. وتبقي الخريطة عدداً قليلاً من لقطات المرشحات الحديثة وتحذف الأقدم.

قد يحتفظ ذلك بتفاصيل تشغيلية حساسة وصور خاصة مصرح بها في ملف المتصفح المحلي. لا تفعّل الميزة إلا على جهاز موثوق ومدار. فهي ليست تشفيراً ولا حاجز صلاحيات ضد من يستطيع الوصول إلى ملف المتصفح. أوقف الخيار أو استخدم **Clear offline data** (مسح البيانات دون اتصال) لحذف السجلات المحفوظة وملفات الصور لهذا المستخدم. يمكن لإجراء **Show saved popup details** (عرض تفاصيل النوافذ المحفوظة) عرض سجلات الكاميرات/الأحداث التي سبق فتحها حتى عند عدم وجود لقطة خريطة مطابقة تماماً؛ ويشير بوضوح إلى أنها سجلات تاريخية محفوظة ويتجاوز عوامل التصفية الحالية. لا يخزن التطبيق بلاطات الخلفية النقطية في المتصفح؛ إذ تظل الخرائط الأساسية دون اتصال معتمدة على ذاكرة Siraj المشتركة من جهة الخادم وعلى إمكانية الوصول إلى خادم Bench. تدعم ميزة المتصفح صفحة خريطة محملة مسبقاً ولقطات مرشحات محفوظة مطابقة تماماً، لكنها لا تجعل غلاف تطبيق Frappe كاملاً متاحاً عند زيارة جديدة والخادم غير متصل. وتظهر العناصر التي لا تملك لقطة مطابقة أو صورة مخبأة كغير متاحة بدلاً من تقديمها على أنها بيانات حالية.

## بنية مجموعات البيانات وحزم البلاطات الخاصة بالموقع

نفذ من مجلد Bench مع تحديد الموقع المقصود صراحة:

```bash
bench --site site.example execute camera_archive_management.setup.storage.ensure_private_storage
bench --site site.example execute camera_archive_management.setup.storage.storage_health_check
```

ينشئ المساعد البنية التالية أو يتحقق منها دون إجراء اتصالات شبكية:

```text
sites/site.example/private/camera_archive_management/
  datasets/<approved-dataset-id>/
  tiles/<approved-tile-pack-id>/
  manifests/
```

يجب اعتماد معرّفات مجموعات البيانات وحزم البلاطات صراحة في `site_config.json`. بعد المراجعة، يمكن للمسؤول ضبط مصفوفتَي JSON مثلاً بالأمرين:

```bash
bench --site site.example set-config camera_archive_dataset_ids '["sample-boundaries"]' --parse
bench --site site.example set-config camera_archive_tile_pack_ids '["local-standard"]' --parse
```

تسمح هذه الإعدادات بالمعرّفات فقط؛ ولا تنزّل المحتوى أو تثبته أو تقدمه. أبقِ مصدر الحزمة وحقوق إعادة توزيعها وإسنادها وتغطيتها خاضعة للمراجعة الإدارية. لا تضع مجموعات بيانات خاصة أو بلاطات مرخصة في Git أو مجلد الأصول العامة.

## عقد البيان، الإصدار 1

يسمى كل بيان JSON بترميز UTF-8 `dataset-<id>.json` أو `tile_pack-<id>.json`، ويستخدم ترتيب مفاتيح حتمياً عندما يكتبه مساعد التخزين. الحقول المطلوبة:

```json
{
  "manifest_version": 1,
  "kind": "dataset",
  "id": "sample-boundaries",
  "version": "2026-01",
  "source": "Operator-provisioned GeoJSON",
  "license": "CC-BY-4.0",
  "attribution": "Dataset provider attribution",
  "bounds": {"west": -10, "south": 35, "east": 5, "north": 60},
  "files": [
    {
      "path": "boundaries.geojson",
      "size_bytes": 1234,
      "sha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
    }
  ]
}
```

الحقل `bounds` اختياري ويستخدم درجات WGS84 العشرية. يكون مسار كل ملف نسبياً إلى مجلد مجموعة البيانات أو حزمة البلاطات المعتمدة؛ وترفض المسارات المطلقة ومكونات `.` و`..` والشرطات العكسية والمسارات المكررة والروابط الرمزية والمسارات الخارجة عن جذر الإعداد. تكون بصمات الملفات SHA-256 بأحرف سداسية عشرية صغيرة. يستطيع مدقق البيان التحقق من حجم كل ملف وبصمته عند طلب ذلك صراحة. لا ينفذ مساعد التخزين الخاص بالموقع استيراداً أو تقديم بلاطات أو تنزيلات خارجية.
