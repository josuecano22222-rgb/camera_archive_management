# Built-in data packs

**العربية:** [توثيق حزم البيانات باللغة العربية](README.ar.md)

## Core application references

- `core_reference_data.json` seeds additive Camera Type and Vehicle Type classifications. Existing records are not modified.
- `natural_earth_admin0_countries.geojson` is the global country-outline and country-level lookup pack. It is Natural Earth 1:110m Admin 0 data pinned to revision `ca96624a56bd078437bca8184e78163e5039ad19` from [nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector). Natural Earth describes the data as public domain in its [project README](https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/README.md).

The bundled GeoJSON SHA-256 is `b587b32dc343c5896752d472f637bb050c8b8eccfbc7e5c8af72ada3072ac226`; the migration checks it before seeding. The polygons are deliberately generalized for global/continental/national map context. They are not cadastral, municipal, operational, legal, or authoritative sovereignty boundaries. The import creates the pinned dataset and missing country boundaries after migration, and selects it as the active dataset only if the site has not selected one already. Higher-resolution administrative and gazetteer data can be imported independently with their own source and license metadata.

## Natural Earth vector geography pack (`natural_earth/`)

`natural_earth/` is a comprehensive, self-hosted Natural Earth vector bundle that powers the map's **Geography layers** panel. It is generated by `scripts/build_natural_earth_bundle.py` from the same pinned revision `ca96624a56bd078437bca8184e78163e5039ad19` and is committed to the repository, so the running application never contacts an external map or statistics API.

- **18 layers, 3,450 features**, spanning cultural geography (countries, states/provinces, boundary lines, disputed boundaries and areas, populated places, airports, ports) and physical geography (land, ocean, coastline, rivers, lakes, glaciated areas, named physical points, named seas, and a 20° graticule).
- **All three geometry families** — points, lines, and polygons — and **all three cartographic scales**: 1:110m global overview, 1:50m regional detail, and 1:10m for airports and ports.
- `catalog.json` records each layer's source URL, feature count, geometry types, bounds, rendering style, and a **SHA-256 integrity pin**. The API verifies every pin before serving a layer and rejects any mismatch.
- The pack is **public domain** (Natural Earth [Terms of Use](https://www.naturalearthdata.com/about/terms-of-use/)); attribution and the revision are retained in the catalog and shown in the map panel.

**Deliberate scope limits.** Roads and railways are not bundled: their only Natural Earth vector source is 1:10m and the files are tens of megabytes (roads ≈ 49 MB, railroads ≈ 38 MB), far beyond a reasonable committed pack and the 25 MiB dataset import cap. The 1:10m polygon themes (countries, lakes, rivers, coastline, land, ocean) are also omitted in favor of the 1:110m/1:50m equivalents to keep the bundle small. Population and GDP figures are Natural Earth's own estimates (circa 2019), not a live statistical database. Like all Natural Earth data, these layers are generalized small-scale cartography — not cadastral, legal, navigation-grade, or live data, and disputed boundaries reflect Natural Earth's default point of view rather than any authoritative sovereignty determination.

To refresh the bundle against a newer pinned revision, edit `REVISION` and the layer list in the build script and run `python3 scripts/build_natural_earth_bundle.py`; then commit the regenerated files. See `docs/natural-earth-vector.md` for the full integration guide.

## Synthetic demo scenario

Demo records are not included in either core data file. They are generated separately by the guarded helper documented in the project README, carry a `CAM-MAP-V1-DEMO` scenario tag, and are excluded from map results unless a user explicitly enables the synthetic-data toggle. The 12 small PNGs in `demo_camera_images/` are original, programmatically drawn illustrations; the generator attaches two distinct views to each synthetic camera. Four tiny PNGs in `demo_vehicle_images/` are original vehicle illustrations used for both per-vehicle images and demo vehicle-type fallback images. None are photographs, camera captures, real vehicle imagery, or operational seed data. Trial records include seven-decimal camera coordinates, four tagged areas, eight vehicles, and 72 Entry/Exit event snapshots with track and nearby-camera context. The generator only runs after explicit site opt-in and operator invocation; its cleanup removes the tagged trial records and their owned attachments.
