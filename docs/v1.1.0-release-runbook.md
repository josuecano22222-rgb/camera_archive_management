# Camera Archive Management v1.1.0 — release runbook

Release **1.1.0** merges the release branch `arena/e4b9cfae-camera-archive-management` into `main` and tags `v1.1.0`. It contains everything since the `v1.0.0` tag (`251cad1`): the archive retirement & credential merge, the comprehensive Natural Earth Vector integration, complete Arabic/English localization, and cache-busted map assets. The verified suite is **153 tests, all passing** on site `frappe.com`.

## What is in this release

1. **Archive retirement & credential merge (destructive migration).**
   - Removes `Archive Asset`, `Archive Ingest Batch`, `Archive Settings`, and the `Archive Integrity` report with **zero trace**, including explicit `DROP TABLE` and `tabSingles` cleanup.
   - Merges `Camera Credential` into `Camera` as seven permlevel-1 fields (System Manager only), re-encrypted through Frappe's standard `__Auth` lifecycle.
   - Patches `merge_camera_credentials` and `remove_archive_doctypes` **fail closed** on any ambiguity. Patch-level detail, safeguards, and troubleshooting live in [`v1.0.0-release-runbook.md`](v1.0.0-release-runbook.md) — read it before migrating any site that still has the legacy DocTypes.
2. **Natural Earth Vector geography (additive, no schema changes).**
   - 18 committed, SHA-256-pinned public-domain layers (cultural + physical; points/lines/polygons; 1:110m, 1:50m, 1:10m for airports/ports), served only from the Bench server.
   - New permission-checked read-only API (`api/natural_earth.py`), country profiles with capital/population/GDP/area, zoom-based scale switching, click-to-inspect, disputed-boundary overlays, and choropleth theming (cameras, movements, NE estimates, custom ISO→number joins).
   - Roads/railways and 1:10m polygon themes are deliberately excluded (source sizes tens of MB); population/GDP are NE estimates, not live data. Full guide: [`natural-earth-vector.md`](natural-earth-vector.md).
3. **Complete Arabic/English translation.**
   - 256 previously untranslated strings translated; `ar.csv` (1,297 rows) and `en.csv` (1,023 rows) cover every JS `__()` literal, Python message, layer label/description, and profile label — verified zero gaps.
   - Country and capital names localize from Natural Earth `NAME_AR` for Arabic users; the geography panel is RTL-correct; a regression test fails on any untranslated feature string.
4. **Asset cache-busting.** The geography JS/CSS URLs carry a content-hash query (`?v=<sha256[:12]>`) computed in `hooks.py`, so browsers fetch fresh assets on a normal refresh after every change.

## Path A — site already updated along the release branch (e.g. `frappe.com`)

Such a site has already run the destructive patches and the full suite. After the merge, switch the checkout to `main` and verify:

```bash
cd ~/frappe-bench/apps/camera_archive_management
git fetch origin
git checkout main
git pull --ff-only
git rev-parse HEAD          # the v1.1.0 merge commit

cd ~/frappe-bench
bench --site frappe.com backup --with-files
bench build --app camera_archive_management
bench --site frappe.com clear-cache
bench --site frappe.com clear-website-cache
bench restart
bench doctor
bench --site frappe.com run-tests --app camera_archive_management   # expect: Ran 153 tests … OK
```

`bench migrate` is safe but not required on this path (no new patches since the branch updates). If the checkout is blocked by local artifacts, stash first (`git stash push -u`) and remove only retired `__pycache__` directories with a targeted `git clean -fdx -- <path>`.

## Path B — upgrading a site still on `v1.0.0`

**Take a full backup and rehearse on a staging clone first.** Archive-media records are permanently deleted by the patches; camera credentials are preserved on `Camera`.

```bash
cd ~/frappe-bench
bench --site <site> backup --with-files
bench --site <site> set-maintenance-mode on

cd ~/frappe-bench/apps/camera_archive_management
git fetch origin && git checkout main && git pull --ff-only

cd ~/frappe-bench
bench --site <site> migrate          # runs merge_camera_credentials + remove_archive_doctypes
bench build --app camera_archive_management
bench --site <site> clear-cache
bench --site <site> clear-website-cache
bench restart
bench --site <site> set-maintenance-mode off
bench doctor
bench --site <site> run-tests --app camera_archive_management
```

If a patch reports an orphan, ambiguous settings row, duplicate credential, or unresolved reference, **stop and inspect** — do not force-delete rows. See the troubleshooting section of [`v1.0.0-release-runbook.md`](v1.0.0-release-runbook.md).

## Post-release verification

- Suite: `Ran 153 tests … OK`.
- Map: open **Camera Archive Map → Geography layers**; enable cultural and physical layers, switch country scale (auto 1:110m ↔ 1:50m at zoom 5), click a country for its profile, apply and clear a choropleth. The panel is a compact docked overlay with legend and Natural Earth attribution.
- Arabic: set the user language to العربية, reload, and confirm the panel, layer names, inspector (e.g. هولندا / أمستردام), and messages are Arabic and the panel docks on the mirrored side.
- Zero trace: no `Archive Asset`, `Archive Ingest Batch`, `Archive Integrity`, `Archive Settings`, or `Camera Credential` DocTypes, tables, links, or fixtures remain.
- Camera credentials: visible/editable only as System Manager (permlevel 1); other roles see stripped reads and resets on write.

## Rollback

Restore the pre-upgrade backup taken above; code alone can be reverted with `git checkout v1.0.0` in the app directory followed by `bench build`, `clear-cache`, and `bench restart`, but **data deleted by the retirement patches is only recoverable from the backup**.

## Standing safeguards

- Synthetic demo records remain strictly opt-in (`camera_archive_allow_demo_data` + explicit operator command), tagged `CAM-MAP-V1-DEMO`, excluded from the map by default.
- Do not modify `siraj_research` or the shared tile cache; tile fetching and cache writes stay disabled until explicitly reviewed and enabled.
- Natural Earth layers are generalized cartography — not cadastral, legal, navigation-grade, or live; disputed boundaries reflect Natural Earth's default point of view.
